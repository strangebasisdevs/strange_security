# Security policy

## Supported versions

Security fixes are made for the latest release, or for the default branch when
the project has no releases. Older versions are not patched.

## Reporting a vulnerability

Report vulnerabilities privately through this repository's Security tab:
**Security -> Report a vulnerability**. Please do not open a public issue, pull
request or discussion for a suspected vulnerability.

Include, as far as you can:

- what is affected (file, component or workflow) and the version or commit;
- the steps or a minimal example that reproduces it;
- the impact you expect, and any mitigation you know of;
- whether the issue is already public or has a deadline.

## What to expect

Reports are acknowledged promptly and handled on a best-effort basis by the
maintainers. You will be told whether the report is accepted, and when a fix is
released. Credit is given on request once a fix is out.
